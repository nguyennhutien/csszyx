## How It Works

```tsx
// You write this
<div sz={{ p: 4, bg: 'blue-500', hover: { bg: 'blue-600' } }} />

// Build time transforms to
<div className="p-4 bg-blue-500 hover:bg-blue-600" />

// Production output (mangled)
<div className="z y x" />
```

The build pipeline has five phases: **type generation** → **JSX transform** →
**Tailwind JIT** → **global mangling** → **checksum injection**.
Each phase is cached for incremental builds.

Open DevTools on this page. Every component above shows mangled class names —
`z`, `y`, `x` — not `p-4` or `bg-blue-500`. That's CSSzyx in production.
