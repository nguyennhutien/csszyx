<Callout label="NEW IN V4.2">
  Logical inset properties: `{ insetS: 4 }` → `inset-s-4` (inline-start),
  `{ insetE: 4 }` → `inset-e-4` (inline-end), `{ insetBs: 4 }` → `inset-bs-4`
  (block-start), `{ insetBe: 4 }` → `inset-be-4` (block-end).
</Callout>

## Examples

```tsx
// Absolutely positioned overlay
<div sz={{ relative: true }}>
  <div sz={{
    absolute: true,
    inset: 0,
    bg: 'black',
    opacity: 50,
  }} />
</div>

// Sticky header
<header sz={{
  sticky: true,
  top: 0,
  z: 50,
  bg: 'white',
  borderB: 1,
  borderColor: 'gray-200',
}} />

// Scrollable container
<div sz={{
  overflow: 'hidden',
  overflowY: 'auto',
  h: 64,
}} />
```
