## Examples

```tsx
// Smooth color transition on hover
<button sz={{
  bg: 'blue-500',
  transition: 'colors',
  duration: 200,
  ease: 'in-out',
  hover: { bg: 'blue-600' },
}} />

// Fade in/out
<div sz={{
  opacity: 0,
  transition: 'opacity',
  duration: 300,
  // Toggle via class: opacity: 100 when visible
}} />

// Loading spinner
<div sz={{ animate: 'spin', size: 6 }}>
  {/* spinner icon */}
</div>

// Staggered entrance with delay
<div sz={{ animate: 'pulse', delay: 100 }} />
<div sz={{ animate: 'pulse', delay: 200 }} />
<div sz={{ animate: 'pulse', delay: 300 }} />

// Respect reduced motion
<div sz={{
  animate: 'bounce',
  motionReduce: { animate: 'none' },
}} />
```
