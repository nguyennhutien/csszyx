## Text Shorthand (size + leading merged)

```tsx
// { text, leading } together → merged single class
{ text: 'lg', leading: 7 }    // → text-lg/7
{ text: 'sm', leading: 'tight' } // → text-sm/tight
```

## Examples

```tsx
// Heading
<h1 sz={{
  text: '4xl',
  fontWeight: 'bold',
  tracking: 'tight',
  leading: 'tight',
  color: 'gray-900',
}} />

// Monospace code label
<span sz={{
  fontFamily: 'mono',
  text: 'xs',
  tracking: 'wider',
  uppercase: true,
  color: 'blue-600',
  bg: 'blue-50',
  px: 2,
  py: 0.5,
  rounded: 'sm',
}} />

// Truncated description
<p sz={{
  text: 'sm',
  color: 'gray-600',
  lineClamp: 2,
}} />
```
