## Examples

```tsx
// Card with elevation shadow
<div sz={{
  shadow: 'lg',
  rounded: 'xl',
  p: 6,
  bg: 'white',
}} />

// Faded disabled state
<button sz={{
  opacity: 50,
  cursor: 'not-allowed',
  disabled: { opacity: 50 },
}} />

// Frosted glass panel
<div sz={{
  backdropBlur: 'md',
  bg: { color: 'white', op: 80 },
  border: 1,
  borderColor: { color: 'white', op: 40 },
}} />

// Blurred background image
<div sz={{
  relative: true,
}}>
  <img sz={{
    absolute: true,
    inset: 0,
    w: 'full',
    h: 'full',
    objectFit: 'cover',
    blur: 'xl',
  }} />
</div>
```
