## Examples

```tsx
// Solid color with opacity
<div sz={{ bg: { color: 'blue-500', op: 20 } }} />

// Linear gradient
<div sz={{
  bgImg: { gradient: 'linear', dir: 'to-r' },
  from: 'blue-500',
  to: 'purple-600',
}} />

// Radial gradient with oklch interpolation
<div sz={{
  bgImg: { gradient: 'radial', in: 'oklch' },
  from: 'cyan-400',
  to: 'blue-700',
}} />

// Background image
<div sz={{
  bgImg: "url('/hero.jpg')",
  bgPos: 'center',
  bgSize: 'cover',
  h: 64,
}} />

// Gradient text
<h1 sz={{
  bgImg: { gradient: 'linear', dir: 'to-r' },
  from: 'blue-600',
  to: 'purple-600',
  bgClip: 'text',
  color: 'transparent',
}} />
```
