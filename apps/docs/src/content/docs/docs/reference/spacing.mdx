## Examples

```tsx
// Card with internal padding and margin
<div sz={{ p: 6, m: 4, bg: 'white', rounded: 'lg' }}>
  <h2 sz={{ mb: 4, text: 'xl', fontWeight: 'bold' }}>Title</h2>
  <p sz={{ mb: 0 }}>Content</p>
</div>

// Centered container
<div sz={{ maxW: '4xl', mx: 'auto', px: 4 }}>
  Page content
</div>

// Inline elements with space between
<div sz={{ flex: true, spaceX: 4 }}>
  <span>Item 1</span>
  <span>Item 2</span>
  <span>Item 3</span>
</div>

// Stack with vertical spacing
<ul sz={{ spaceY: 2 }}>
  <li>First item</li>
  <li>Second item</li>
</ul>
```
