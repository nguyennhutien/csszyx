## Examples

```tsx
// Hover scale effect
<img sz={{
  transition: 'transform',
  duration: 300,
  hover: { scale: 105 },
}} />

// Rotate on active
<button sz={{
  transition: 'transform',
  active: { rotate: 3 },
}} />

// Centered absolute overlay
<div sz={{
  position: 'absolute',
  top: '1/2',
  left: '1/2',
  translateX: '-1/2',
  translateY: '-1/2',
}} />

// Card flip animation
<div sz={{
  position: 'relative',
  transformStyle: '3d',
  hover: { rotateY: 180 },
}} />
```
