---
title: Public API
description: Which package entries follow semver, which serve generated code, and which are internal.
---

Every csszyx package pins the others to its own version, so an entry one csszyx
package imports from another changes with them. This page names the entries you
may import, the entries the compiler writes imports to, and the entries that
connect the packages. A change to a public entry follows semver; a change to an
internal one ships in the same release as every package that reads it.

| Kind | Meaning |
| --- | --- |
| public | Import it, or name it in a config file. Changes follow semver. |
| generated | The compiler writes imports to it. Keep the version the build installed; do not import it yourself. Its exports change only by adding names. |
| internal | Connects csszyx packages. Not for import; it can change in any release. |

A name an entry exports with a leading `_` or `__`, or one marked `@internal`
in its types, is written by the compiler or used by csszyx's own packages, and
follows the entry's kind above only for code the compiler wrote.
