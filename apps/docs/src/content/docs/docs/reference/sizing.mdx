## Logical Sizing (v4.2)

:::tip[New in v4.2]
`blockSize` is the logical equivalent of `height` (maps to `block-size`).
`inlineSize` is the logical equivalent of `width` (maps to `inline-size`).
These follow the writing direction and are useful for RTL/vertical text.
:::

## Examples

```tsx
// Responsive sizing
<img sz={{
  w: 'full',
  h: 48,
  objectFit: 'cover',
  md: { h: 64 },
  lg: { h: 96 },
}} />

// Square icon
<div sz={{ size: 10, rounded: 'full', bg: 'blue-500' }} />

// Constrained content width
<main sz={{ maxW: '4xl', mx: 'auto', px: 4 }}>
  Content
</main>

// Full viewport height with scrollable body
<div sz={{ minH: 'screen', display: 'flex', flexDir: 'col' }}>
  <header />
  <main sz={{ display: 'flex', grow: true }} />
  <footer />
</div>
```
