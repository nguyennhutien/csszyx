v0.4.0 — @csszyx/dynamic, CLI, MCP server, VS Code extension, compiler hardening.

### New packages

- **`@csszyx/dynamic`** — runtime CSS injection engine. Delta-injects only styles not already in the pre-built stylesheet; accepts both mutable `SzObject` and `as const` (`ReadonlySzObject`) inputs. Ships `@csszyx/dynamic/react` helper.
- **`@csszyx/mcp-server`** — Model Context Protocol server exposing `lookup`, `reverse`, `expand`, `batch`, `migrate`, `theme`, and `validate` tools for AI agents.
- **VS Code extension** — sz prop completion, hover, diagnostics, and TextMate grammar for syntax highlighting.

### Compiler

- New `css: {}` sub-prop as an arbitrary CSS escape hatch (replaces `NEEDS_ARBITRARY_PROPERTY`).
- Build-time ternary literal compilation (e.g. `sz={{ p: isLg ? 8 : 4 }}` → `p-8` / `p-4`).
- Build-time variable and spread resolution with dev-mode safety guard; dev-mode diagnostics on sz runtime fallback explain why and suggest `szv` or `dynamic()`.
- New exports: `PROPERTY_MAP`, `KNOWN_VARIANTS`, `BOOLEAN_SHORTHANDS`, `SUGGESTION_MAP`, `ReadonlySzObject`, `ReadonlySzValue`.
- New props: `animationDelay`, `insetRing` / `insetRingColor` (Tailwind v4.2).
- Fixes: variant prefix propagation to `filter` / `dropShadow` / `ease` / `animate` / `origin` arbitrary classes; hex/rgb/hsl color opacity wrapping (`{ color: '#0d0d12', op: 90 }` → `bg-[#0d0d12]/90`); opacity formatter — sub-half-step decimals use `/[0.05]`, integer and half-step use `/50`; CSS variable in color object form now wraps in `()`; `bgRepeat` x/y normalization; `content` double→single quote; stripping of user-provided `[]` brackets on arbitrary values; `SpacingScale` and `FractionValue` type expansion.
- Removed: `scale3d` / `translate3d` booleans (use `scale: '3d'` / `translate: '3d'`), duplicate transform props.

### Unplugin

- Attribute merging: `sz` prop merges cleanly with existing `className`.
- Theme auto-scan: reads Tailwind `@theme` CSS blocks and generates `.csszyx/theme.d.ts` for IntelliSense on custom design tokens; warns when `tsconfig.json` is missing the entry (dev only).
- HMR incremental class discovery — only re-scans changed files in dev mode.
- Mangling hardening (all 3 passes): escaped-quote handling in class string literals, SSR regex fix for unminified `className: \`` form, HeroSection production mangling fix.
- Webpack dev-mode: skip class mangling to avoid source map corruption; escape `"` in mangle map inside `eval()`-wrapped modules to prevent `SyntaxError: missing ) after argument list`.

### CLI

- HTML file support (`class=` → `sz=` conversion).
- New options: `--braces`, `--no-fouc`, `--inject-runtime (local|cdn)`, `--cdn-url`, `--local-path`.
- `transform-gpu` / `cpu` / `none` moved from boolean to value map in reverse-map; arbitrary bracket opacity values (`[0.05]`) now parse to numbers.

### Runtime

- New `variants` entry — small helper for variant composition.

### Docs

- Pagefind search modal in docs site.
- `scripts/check-corpus.ts` — round-trip validator over pinned Catalyst / Flowbite / Radix / shadcn / Tremor snapshots (`pnpm corpus:check`); CI gate added alongside `property-map-coverage.test.ts`.
- Full spec + mdx reference + `llms.txt` / `llms-full.txt` sync for transforms, filters, backgrounds, and new props.

### Release hygiene

- `@csszyx/vscode-extension` marked `private: true` to prevent accidental npm publish.
